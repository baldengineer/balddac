# Bald DAC Wing

Open hardware KiCad project for a two-channel, high-speed digital-to-analog converter (DAC) board.

The design is built around the Analog Devices AD5447 dual 12-bit multiplying current-output DAC and includes fast output amplification, a precision reference, digital interface logic, coaxial outputs, and test points. Revision 1 has been prepared for fabrication.

## Features

- Dual 12-bit current-output DAC channels
- AD8065 high-speed output amplifier stages
- REF3425 2.5 V voltage reference
- Parallel digital interface with registered/control logic
- Separate coaxial outputs for DAC A and DAC B
- 3.3 V digital power and dedicated analog/reference power nets
- Four-layer PCB stackup with internal copper planes
- Custom KiCad symbols for project-specific parts
